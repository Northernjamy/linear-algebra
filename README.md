## Course Overview

This course introduces the mathematical foundations of linear algebra and explores their computational applications through theoretical study and programming exercises.

The curriculum covers fundamental concepts, mathematical algorithms, and applications relevant to scientific computing and artificial intelligence.

### Topics Covered in the Curriculum

- **Linear Systems:** Linear equations, Gaussian elimination, and solution methods
- **Matrix Theory:** Matrix operations and special matrices
- **Determinants:** Determinant computation and properties
- **Matrix Inversion:** Gauss-Jordan elimination and adjugate-based methods
- **Cramer's Rule:** Solving linear systems using determinants
- **Vector Spaces:** Linear combinations, subspaces, and linear independence
- **Basis and Dimension:** Basis vectors, coordinate systems, dimension, and rank
- **Linear Transformations:** Coordinate changes and transformations
- **Applications:** Markov chains and computational approaches to linear algebra
